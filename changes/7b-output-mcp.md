Changed

`mcp serve` keeps stdout for JSON-RPC from the start, also with `--json`: an error before the session, such as a folder too wide to serve without `--root`, is now text on stderr only, where it was also a JSON document on stdout before. Clap errors such as an unknown flag stay JSON with `--json`. The text of a usage error is unchanged: clap's first paragraph without `error: ` is the what, its tips, possible values and usage line are the fix, the code is `usage` and the exit code 2. Inside, one function builds a usage error, `main` decides who writes stdout instead of a static flag, and the MCP server holds its root and offered commands as plain fields (record 0010, step 7b). The removed stdout flag (`reserve_stdout_for_mcp`) and `clap_message` stay in the history of `main`: `4defaae` has them (`apps/carrysheet-cli/src/output.rs`, `apps/carrysheet-cli/src/mcp.rs`).
