Removed

The crates `carrysheet-commands`, `carrysheet-kernel` and `carrysheet-model`, folded into one library crate, `carrysheet`, as its modules `commands`, `kernel` and `model`; `carrysheet-cli` depends on it. Unit tests moved out of the code files into `src/tests/`. Also removed: `scripts/check.mjs`, `scripts/check.test.mjs`, `scripts/output.mjs` and `scripts/release-check.mjs`. CI now runs plain cargo steps, and the Rust version is pinned in `rust-toolchain.toml`. The release privacy scan still checks a Linux release build for the home folder, `/home/` paths, the user name and email addresses. `carrysheet-cli` behaves as before. The old crates and scripts stay in the history of `main`: `275442a` is the last commit that has them, as does every commit before this change (record 0010, decision 4, step 3).
