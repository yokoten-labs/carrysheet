Changed

File access moved from the library into the program (record 0010, decision 2). `carrysheet::run` now takes the file's bytes and gives back an `Answer` with the JSON fields and, for a save, the bytes to write; `Kernel::open` is gone, and the library's errors no longer replace the home folder with `~`. `carrysheet-cli` does that for every error, log line and path it shows, and `--root` works as before on the command line and over MCP. What a user can notice: a call with a bad argument and also a file that cannot be used now names the file's problem first; `edit` reports an existing output file before an error in `ops`; and on the command line an output path that is a broken link is replaced by a regular file instead of written through. A workbook that is too large is still refused from its size, before any byte is read.
