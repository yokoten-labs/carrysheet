Removed

The `macros` command and its readers (`carrysheet-vba`, `carrysheet-cfb`), MCP over HTTP (`mcp serve --http`, `--token-file`, `--allow-writes`, `docs/mcp-http.md`), `mcp serve --log-file`, the `feedback` command, the placeholders `check`, `sanitize`, `mcp install` and `mcp doctor` (issue 102), and the y/N question at a terminal. Nobody is asked any more: a call that needs a confirmation fails with a three-part error that names `--confirm`, `--confirm-loss` and `--yes`. The MCP server logs to stderr only, cleaned like text from a file. `overview` gains a `macros` field when an .xlsx, .xlsm or .xlsb file holds a VBA project or Excel 4 macro sheets, found by part name and by content type, so a renamed part is found too: they are never run, and a save keeps them where the format can hold them. For .xls and .ods files, a zip it cannot list, and content types it cannot read or that use character references or UTF-16, the field says macros were not checked. `deny.toml` now bans HTTP and TLS crates and fences GridCraft to `carrysheet-kernel` and rmcp and tokio to `carrysheet-cli`. The code stays in the history of `main`: `47dfd01` has it, as does every commit before this change (record 0010, decision 4, step 2).
