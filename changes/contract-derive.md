Changed

Each command's arguments are now one Rust struct: the single source of its flags, its MCP tool schema and its help (record 0010, decisions 2 and 6). The MCP tool list and `commands --json` do not change by one character. Some messages read differently. In `--help` and in usage errors, a flag's value shows the flag's name in capitals, such as `--max-rows <MAX_ROWS>` and `--mode <MODE>` (before: `<N>` and `<mode>`), and an argument's help line has no full stop at the end. The reason in an error about a wrong argument now comes from the type check, such as `invalid type: string "abc", expected u32` (before: `` `max_rows` must be a whole number from 1 to 10000, but it is the text "abc" ``), and is cut at 300 characters. Its fix line still says what to send, such as `` Give `format` as one of xlsx, xls, csv. ``, and then gives the argument's description. An error inside `ops` names the operation, such as `ops[2]`, and no longer the field inside it; its fix line lists an operation's fields with an example. On the command line, a negative number such as `--max-rows -5` is now a usage error from the flag parser. Error codes and exit codes do not change.
