Removed

The layers between the commands and GridCraft: the `Engine` trait and `SheetView`, the memory engine with the `test-engine` feature, and the `model` module with its own cell, value and workbook types. The library is now `lib.rs` (one command, the limits, the caught panic), `open.rs`, `view.rs`, `edit.rs`, `save.rs`, `range.rs` and `error.rs`; cells and ranges are GridCraft's `CellRef` and `RangeRef`, and `range.rs` adds only the sheet name, the `$` marks and the reasons. `carrysheet-cli` prints the same JSON, error codes and exit codes. Two things differ for a range that was already refused or odd: a range that is not cells, whole columns or whole rows gets one reason instead of several, and a row number written with more than 7 digits (`A00000001`) is refused. The code stays in the history of `main`: every commit before this change still has it, in `crates/carrysheet/src/commands/engine` and `crates/carrysheet/src/model` after step 3, and in `crates/carrysheet-commands`, `crates/carrysheet-kernel` and `crates/carrysheet-model` before it (record 0010, decision 4, step 4).
