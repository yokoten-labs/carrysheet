Changed

`overview` no longer takes `response_format`; it only widened the header row, which `overview` no longer shows (record 0010, decision 11). A call to `overview` that still passes `response_format` is now refused: `invalid_argument` over MCP ("`overview` has no argument named `response_format`"), a usage error on the command line. This breaks any caller that sent it. The `confirmation_required` error no longer repeats the whole call in its fix: it says to call again with the same arguments and `"confirm":true`, or to add `--confirm` on the command line. The error code `declined` is gone; nothing asks a question any more, so no command returned it. The texts of `convert` name xlsx and csv only. Removed from the library, unused in the workspace: `text::terminal`, `text::has_hidden`, `text::UNICODE_VERSION` and `ErrorCode::Declined`. They stay in the history of `main`: `4defaae` has them (`crates/carrysheet/src/text.rs`, `crates/carrysheet/src/error.rs`).
